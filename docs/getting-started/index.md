# Getting Started with WolfGuard

Welcome to WolfGuard! This guide will help you get up and running with your own OpenConnect VPN server compatible with Cisco Secure Client.

## What is WolfGuard?

WolfGuard is a modern, high-performance OpenConnect VPN server built with:

- **WolfSSL** - Modern cryptographic library with TLS 1.3 support
- **C23 Standard** - Latest C language features for safety and performance
- **Cisco Compatibility** - Full compatibility with Cisco Secure Client 5.x+
- **Security First** - Built with security best practices from the ground up

## Who Should Use This Section?

This section is designed for **simple users** who want to:

- Quickly install WolfGuard on their server
- Set up their first VPN connection
- Understand basic configuration
- Get answers to common questions

## What You'll Need

Before you begin, make sure you have:

- A Linux server (Ubuntu 22.04+, Rocky Linux 9+, or similar)
- Root or sudo access
- Basic command-line knowledge
- A domain name (optional but recommended)
- 30 minutes of time
